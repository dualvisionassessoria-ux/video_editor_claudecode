# Editor de vídeo profissional no Claude Code

Este repositório contém skills para editar vídeos (Reels, Shorts, YouTube). Quando a pessoa pedir para editar, cortar, legendar ou melhorar um vídeo, use a skill `edicao-video` (orquestrador) e siga as regras fixas dela: voz sem ruído, ritmo rápido e enxuto, cortar erros e repetições, música de fundo bem baixa, vertical 1080x1920, revisões como "versão 2", "versão 3".
Responda em português do Brasil. A identidade visual vem de `config/marca.json`.
